五子棋 · 人机对战

适用系统：64 位 Windows 11，或 Windows 10 1903 及以上版本。
完整解压压缩包，打开「五子棋」文件夹，双击「开始游戏.cmd」即可开始。
也可以直接双击 gomoku-ui.exe。程序、运行库和中文字体已随包提供，无需安装 Lean。
发给朋友时，发送整个压缩包即可。

怎么玩
左键点击棋盘交叉点落子。默认你执黑先手，电脑执白。
右上角可切换「人机对战 / 双人对弈」，也可换为执白，让电脑先手。
切换模式、换边都会开始新局。
横、竖、斜线连续五子或更多获胜；无禁手，满盘无胜者为和棋。

快捷键
U：悔棋。人机模式撤销你和电脑的一轮落子，双人模式撤销一步。
R：重新开始。
N：显示 / 隐藏落子序号。
M：切换对战模式。
B：人机模式换边。
Esc：退出。

电脑思考时会显示提示；此时仍可悔棋、重开、换边或切换模式。
你执白时，悔棋会保留电脑的第一手。窗口可调整大小。

本游戏用 Lean 4 编写游戏规则、人机算法及界面逻辑，使用 raylib 绘图。
第三方许可证见 licenses 文件夹及「第三方说明.txt」。
